## 一、识别（11-21 晚）

| 尝试 | 结果 |
|---|---|
| 插 USB | 只显示 USB 网络共享 |
| 开 USB 调试 | 始终无 ADB |
| 查 USB 描述符 | `Unisoc Phone` / `VID_1782` → **戳穿"骁龙 888"** |
| 虚拟光驱 | 只有展锐 2019 年示例文件 |
| 无线调试 | 扫 28k 端口，0 个监听 |
| DSU | 能装，重启仍回原系统 |
| CPU-Z | T616 / 12nm / Mali-G57 / 假 10 核 |
| 分区表 | 81 项，58.2 GiB → **64GB** |

**修正过一次错误**：一开始按 4KB 单位算成 233GB，错判"256GB 是真的"；实际单位是 1KB。

## 三、BROM（11-21 21:00）

| 尝试 | 结果 |
|---|---|
| 翻设备历史 | 发现 `VID_1782&PID_4D00` |
| 按键组合 | 音量减 + 电源 + 插线 → 黑屏，"叮" |
| 官方驱动 | 证书 2017 年过期，装不上 |
| Zadig + WinUSB | ✅ 成功 |
| spd_dump | 报 `bad checksum` → 发现自己实现要 CRC16 |

## 四、CVE（11-21 22:20）

| 尝试 | 结果 |
|---|---|
| 先写载荷再 END | 设备复位 |
| 载荷不 END | BROM 不理后续命令 |
| **先载 FDL1 → 载荷 → END** | **成功** |
| 下载块 4096 | 被拒 → 改 528 |
| 读取块 2112 → 32768 | 速度 0.08 → **0.67 MB/s** |

## 五、备份（11-22 上午）

8 个镜像：`splloader` / `uboot_a` / `boot_a` / `dtbo_a` / `init_boot_a` / `vbmeta_a` / `misc` / `miscdata`

- `boot_a` 头 `ANDROID!` ✅
- `init_boot_a` 全零（空分区）
- `miscdata[8192:8256]` = 64 个零 → **锁定**
