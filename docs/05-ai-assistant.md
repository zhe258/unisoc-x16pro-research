# 05 · 内置语音助手分析（讯飞 AIUI）

## 这是一台什么机器上的 AI

广告 ROM 里通常塞一个"智能助手"。这台机器的助手：

```
应用名 : PrizeSmartAssistant
路径   : /system/priv-app/          ← 系统特权应用
方案   : 科大讯飞 AIUI v2
```

**不是杂牌自研，是讯飞 SDK + ROM 商套壳。**

---

## 工作链路

```
唤醒词  → ivw/mlp.bin（本地神经网络，离线）
   ↓ 唤醒
录音    → WSS 上传云端
   ↓
ASR     → 云端转文字
   ↓
对话    → 云端模型
   ↓
TTS     → 云端合成回传
```

**除了唤醒词，其余全部在云端。**

### 本地文件

```
/sdcard/AIUI/
├─ ivw/<厂商>/L/
│  ├─ keywords.bin   唤醒词词表
│  ├─ mlp.bin        唤醒词神经网络
│  ├─ res.bin        声学资源
│  └─ vtn.ini        配置
└─ msc/              语音 SDK 的日志目录
```

## 能力实测

| 项目 | 结果 | 说明 |
|---|---|---|
| 知识 | ✅ 中档 | 技术问题能详答 |
| 推理 | ✅ 好 | 水池题（3h/6h/4h）算出 4 小时，过程正确 |
| 逻辑 | ✅ 好 | 识别"昨天=明天的前天"是恒等式，答"无唯一解" |
| 算术 | ✅ 好 | 第 50 个质数答 229（正确）；连减 48 步无错 |
| 代码 | ✅ 能写 | 括号匹配函数带注释 |
| 写作一致性 | ✅ 好 | 五轮测试人名/设定/年份/人称全稳，插话能拉回 |
| **意图路由** | ❌ **极差** | "列出 100 以内质数" → 报"未发现导航软件" |
| 本地工具 | ❌ 仅闹钟 | 打不开 WiFi、读不了电量、不能放音乐 |
| 联网搜索 | ❌ | 无 |
| 识图 | ❌ | 无 |
| 输出长度 | ⚠️ 约 400–500 字 | 超了会自己说"此处省略" |
| 位置 | IP 定位 | 报出的是 IP 归属地，不是 GPS |

### 关键判断：好模型 + 烂路由

```
语音 → ASR → [意图分类器] ─┬→ 本地动作（仅闹钟）
                            ├→ 聊天模型（云端）
                            └→ 兜底话术
```

大量"弱智表现"**不是模型的锅**：

| 现象 | 真实原因 |
|---|---|
| 打哈哈、说俏皮话 | 分类器判定后走兜底 |
| "我要去扩充曲库了" | 没认出"播放音乐" |
| **质数 → 导航** | 关键词误匹配 |

### 五轮写作测试（可复现）

```
1. 写 200 字小说：主角林舟，在"从不下雨"的城市开旧书店
2. 继续：一个自称认识他父亲的女人进店
3. 继续：让女人说出一个具体年份
4. 问天气（干扰），再问"刚才那个女人说的年份是多少"
5. 把前三段合并成 100 字摘要
```

本机全过：人名稳定、设定未破、"从不下雨"保持、年份一致、插话后能拉回。

## 隐私提示

以下是对**使用者**的提醒，不涉及任何技术细节：

| 事实 | 含义 |
|---|---|
| 唤醒词在本地识别 | 不联网也能唤醒 |
| **唤醒后的语音需要上云** | 说话内容会经过云端才能变成文字 |
| 本地日志会留存识别文本 | 文件在 `/sdcard`，可被有存储权限的应用读取 |
| 位置来自 IP | 设备没有 GPS 权限，服务端按出口 IP 推断 |

**实际建议：**

1. **不要对语音助手说真实信息**（地址、姓名、验证码、银行卡）
2. 定期清理 `/sdcard/AIUI/` 下的日志
3. 如果不需要，关掉语音唤醒

---

## 结论

> **中档模型 + 糟糕意图路由 + 系统特权应用。**

**能用，但别对它说真话。** 它的定位是"会聊天的语音入口"，不是智能管家。
