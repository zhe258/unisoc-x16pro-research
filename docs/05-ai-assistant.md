# 05 · 内置语音助手分析（讯飞 AIUI）

## 这是一台什么机器上的 AI

广告 ROM 里通常塞一个"智能助手"。这台机器的助手：

```
应用名 : PrizeSmartAssistant
路径   : /system/priv-app/          ← 系统特权应用
方案   : 科大讯飞 AIUI v2
```

**不是杂牌自研，是讯飞 SDK + ROM 商套壳。**

---

## 工作链路

```
唤醒词  → ivw/mlp.bin（本地神经网络，离线）
   ↓ 唤醒
录音    → WSS 上传 aiui.xf-yun.com
   ↓
ASR     → 讯飞云端转文字
   ↓
对话    → 讯飞云端模型
   ↓
TTS     → 云端合成回传
```

**除了唤醒词，其余全部在云端。**

### 本地文件

```
/sdcard/AIUI/
├─ ivw/<厂商>/L/
│  ├─ keywords.bin   唤醒词词表
│  ├─ mlp.bin        唤醒词神经网络
│  ├─ res.bin        声学资源
│  └─ vtn.ini        配置
└─ msc/aiui*.log     讯飞 SDK 日志
```

| 位置 | IP 定位 | 报青岛（无 GPS） |

### 关键判断：好模型 + 烂路由

```
语音 → ASR → [意图分类器] ─┬→ 本地动作（仅闹钟）
                            ├→ 聊天模型（云端）
                            └→ 兜底话术
```

大量"弱智表现"**不是模型的锅**：

| 现象 | 真实原因 |
|---|---|
| 打哈哈、说俏皮话 | 分类器判定后走兜底 |
| "我要去扩充曲库了" | 没认出"播放音乐" |
| **质数 → 导航** | 关键词误匹配 |

### 五轮写作测试（可复现）

```
1. 写 200 字小说：主角林舟，在"从不下雨"的城市开旧书店
2. 继续：一个自称认识他父亲的女人进店
3. 继续：让女人说出一个具体年份
4. 问天气（干扰），再问"刚才那个女人说的年份是多少"
5. 把前三段合并成 100 字摘要
```

本机全过：人名稳定、设定未破、"从不下雨"保持、年份一致、插话后能拉回。

## 隐私发现

### ① 用户语音的识别文本被明文记录

日志中：

```json
"cbm_tidy": {"text": "{\"query\":\"<用户原话>\",\"intent\":[...]}"}
```

实测抓到 3 条真实查询。**文件在 `/sdcard`，任何有存储权限的应用都能读。**

### ② 鉴权参数被写进日志

日志里 WebSocket 的 URL 带一段 base64：

```
authorization=YXBpX2tleT0i...    ← base64
```

解码后是：

```
api_key="6c81c6b4****（已打码）",
algorithm="hmac-sha256",
headers="host date request-line",
signature="<每次请求现算>"
```

- `signature` 一次性（含日期）
- **`api_key` 是长期凭证**

> ⚠️ 本项目**不包含完整密钥**。这是厂商的集成失误，不应被利用。

### ③ 语音必须上云

云端架构决定：除唤醒词外，全部语音要上传 `aiui.xf-yun.com` 才能识别。
