# 一台 165 元"骁龙 888"手机的完整拆解

> **Unisoc T616 山寨机的硬件取证、BROM 逆向与解锁边界实测**

2026 年 11 月，我在一台标称「骁龙 888 / 16GB / 256GB / 5G」的杂牌安卓机上做了一次完整体检。

结论先说：

- **参数全是假的**——真实芯片是展锐 T616（12nm），存储 64GB，4G 网络
- **系统是广告 ROM**——PRIZE 公版，锁死引导，用户无法刷机
- **底层通道能打通**——通过 CVE-2022-38694 进了 BROM，可以读写任意分区
- **但引导改不了**——用单字节实验证明 `splloader` 受 BootROM 整体校验，任何修改都不会启动

## 三个最有价值的发现

### 1. USB 描述符是最硬的证据

```
BusReportedDeviceDesc : Unisoc Phone
HardwareIds           : USB\VID_1782&PID_5D20
```

`VID_1782` 是紫光展锐。**`build.prop` 改不到这个字段**，一秒钟戳穿"骁龙 888"。

### 2. BROM 的 CVE 打法有严格顺序

```
先载 FDL1  →  再写 ROP 载荷  →  最后发 END 触发跳转
```

顺序错了设备直接复位——因为跳转发生时 FDL1 还没进内存。

### 3. 单字节实验可以分清"补丁错"和"镜像受保护"

往 `splloader` 的**全零填充区**改 1 个字节（不涉及任何代码）：

- 能启动 → 镜像未受保护，可以折腾
- **黑屏 → 镜像被 BootROM 校验，解锁无望**

这台机器是后者。

## 协议细节速查

| 项目 | 说明 |
|---|---|
| BROM 模式 | `VID_1782 & PID_4D00`，按住音量键 + 插线 |
| MTP | `PID_4001` ｜ 网络共享 `PID_5D20` ｜ 虚拟光驱 `PID_5D03` |
| 帧格式 | `0x7e` 包裹，`0x7d` 转义（`7d/7e` → `7d` + `^0x20`） |
| 校验 | **BROM 阶段 CRC16，FDL 阶段求和** |
| 下载块 | **≤528 字节**（4096 会被拒） |
| 读取块 | **32768 字节**（65535 会失败） |
| 实测速度 | 读 0.67 MB/s，写约 160 KB/s |
